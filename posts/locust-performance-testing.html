Locust 实战：百万级并发性能测试实践

性能测试2023年12月20日

Locust 是一款用 Python 编写的现代性能测试工具，以其简洁的代码编写方式和出色的分布式能力受到越来越多开发者的青睐。本文将分享如何使用 Locust 进行百万级并发的性能测试实践。

一、为什么选择 Locust？

  • 代码即配置：用 Python 代码编写测试场景，比 JMeter 的 GUI 操作更灵活
  • 分布式支持：原生支持分布式压测，轻松扩展到多台机器
  • 实时监控：内置 Web UI，实时查看性能指标
  • 资源友好：基于协程，单台机器可模拟上万并发

二、基础测试脚本

from locust import HttpUser, task, between, events
import random

class WebsiteUser(HttpUser):
    wait_time = between(1, 3)  # 用户思考时间 1-3 秒
    
    def on_start(self):
        """每个虚拟用户启动时登录"""
        self.client.post("/api/login", json={
            "username": f"user_{random.randint(1000, 9999)}",
            "password": "test123"
        })
    
    @task(3)  # 权重为 3，更频繁执行
    def view_dashboard(self):
        self.client.get("/api/dashboard")
    
    @task(2)
    def view_profile(self):
        self.client.get("/api/profile")
    
    @task(1)
    def update_profile(self):
        self.client.patch("/api/profile", json={"nickname": "test_user"})

三、分布式压测部署

当单台机器不足以支撑所需并发时，可以使用分布式模式：

# Master 节点
locust -f locustfile.py --master --master-bind-host=0.0.0.0

# Worker 节点（在多台机器上执行）
locust -f locustfile.py --worker --master-host=

四、性能指标分析

重点关注以下核心指标：

  • 响应时间：P50、P95、P99 分位数，而非平均值
  • 吞吐量（RPS）：每秒处理的请求数
  • 错误率：失败请求占比
  • 系统资源：CPU、内存、网络、磁盘 IO

五、最佳实践

  • 梯度加压，观察系统性能拐点
  • 测试数据预生成，避免压测时的 IO 瓶颈
  • 监控被测系统的各项指标，定位性能瓶颈
  • 每次测试后清理数据，保证测试环境一致性

性能测试不仅仅是为了得到一个数字，更重要的是理解系统的性能极限，找到瓶颈并持续优化。
