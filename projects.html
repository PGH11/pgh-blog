playwright-pytest-framework

基于 Playwright 和 Pytest 构建的企业级自动化测试框架。 采用 Page Object 模式设计，支持多环境配置、并行执行、 Allure 精美报告，开箱即用的企业级测试解决方案。

✨ 核心特性

  • ✅ Page Object Model 架构设计
  • ✅ 多环境配置支持（开发/测试/生产）
  • ✅ 分布式并行测试执行
  • ✅ Allure 测试报告深度集成
  • ✅ 失败自动截图与重试机制
  • ✅ CI/CD 流水线无缝集成
